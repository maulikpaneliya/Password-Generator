# Password Generator

> **Private Project – Not for Public Use**

**Password Generator** is a web application designed to create secure, random passwords based on user-defined criteria. Built with HTML, CSS, and JavaScript, it offers a simple interface to quickly generate strong passwords for personal use.

## Features

* Generate random passwords instantly
* Options to include:

  * Uppercase letters
  * Lowercase letters
  * Numbers
  * Special characters
* Adjustable password length
* Copy-to-clipboard functionality

## Technologies Used

* **HTML** – Web page structure
* **CSS** – Styling and user interface design
* **JavaScript** – Password generation logic and interactivity

## Status

This is a private utility tool developed for internal or personal use. It is not intended for public release or general distribution.
